# lab-product-landing-page

Page produit statique HTML/CSS, prête pour GitLab Pages.

## Publication
1. Créez un projet GitLab nommé `lab-product-landing-page`.
2. Décompressez l'archive et placez les fichiers à la racine du dépôt (y compris `.gitlab-ci.yml`).
3. Commitez et poussez sur la branche par défaut.
4. Consultez **Build > Pipelines**, puis **Deploy > Pages** pour obtenir l'URL du site.

La pipeline copie `index.html` et `styles.css` dans `public/` et publie ce dossier avec GitLab Pages.

Le logo, les icônes, la police et la vidéo sont chargés depuis des services externes et nécessitent une connexion Internet.
